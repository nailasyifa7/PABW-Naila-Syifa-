# Worksheet PABW Pertemuan 9 — Naila Syifa Wiharningtyas

Versi ini melanjutkan proyek mie goreng dari P8 dan menambahkan latihan DOM, event delegation, filter proyek, serta validasi form.

## Menjalankan
1. Buka folder `worksheet-p9` di VS Code.
2. Jalankan `profil.html` menggunakan Live Server (jangan dibuka sebagai file lokal biasa).
3. Uji tombol filter Semua, Web, dan Data.
4. Uji form Tambahan Menu dengan kolom kosong, spasi, dan input yang valid.
5. Buka DevTools → Console dan pastikan tidak ada galat.

## Berkas utama
- `profil.html`: halaman profil dan wadah proyek.
- `js/app.js`: data profil, menu, dan array proyek yang diekspor.
- `js/dom.js`: render DOM, filter dengan satu pendengar induk, dan validasi form.
- Berkas CSS dan `mie.jpg`: desain dari P8.
